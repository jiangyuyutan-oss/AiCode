# 语音输入

手不动键盘，把需求「说」进输入框：聊天输入框工具栏新增麦克风按钮，点一下开始听写，说话内容实时出现在输入框里，再点一下停止，识别文本追加在已输入内容之后。

## 怎么用

1. 点击输入框工具栏的 **麦克风** 图标。
2. 首次使用会请求麦克风权限，允许后自动开始听写。
3. 对着手机说出需求，识别文本实时填入输入框。
4. 说完点击 **停止** 图标（原麦克风位置），文本定稿并追加在你已输入的内容后面。
5. 像平常一样点发送，或继续补充修改。

识别文本只进输入框，由你确认后才发送——可以边说边改。

## 说明

- **语言**：跟随系统语音识别语言设置。
- **追加合并**：识别文本与已有内容以空格分隔拼接，不会覆盖你打好的字；可连续多次听写叠加。
- **设备支持**：依赖系统语音识别服务（`SpeechRecognizer`），少数 ROM 未预装时点击会提示「当前设备不支持」。
- **权限**：麦克风权限（RECORD_AUDIO）仅用于语音听写，拒绝后功能提示但其他功能不受影响。

## 常见问题

::: tip 点了没反应或提示未听清
确认麦克风权限已授予；周围环境太吵或语速过快可能导致识别不到，再试一次。
:::

::: tip 识别结果不准
可以在停止后手动修改输入框文本再发送；专有名词、代码符号类内容建议打字输入，识别准确率更高。
:::
