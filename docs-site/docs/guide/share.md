# 接收外部分享

从浏览器、代码编辑器、剪贴板工具等任意支持系统分享菜单的 App，把选中的文本或图片发给 AiCode，让 AI 直接分析，省去手动复制粘贴。

## 怎么用

1. 在外部 App（如浏览器看到一段报错、IDE 里选中一段代码）长按或菜单选「分享」。
2. 分享菜单里选 **AiCode**。
3. AiCode 打开（或切回前台），分享内容填入聊天输入框。
4. 你可以补充一句指令（如「分析这段报错」「给这段代码加注释」），再点发送。

内容默认只填入输入框，不会自动发给 AI——给你补指令和确认的机会。

## 文本与图片

- **纯文本**：分享菜单带文本（`text/plain`）即填入输入框。多次连续分享会换行拼接，保留每段内容。
- **图片**：分享图片（`image/*`，如截图、相册图）会加入输入框附件区，走与手动选图相同的识图链路。需当前模型支持视觉（见 [默认与专用模型](./default-models)）。

文本和图片可同时分享（图片带文字说明时）。

## 冷启动与热启动

- **App 没开时**从分享菜单拉起：AiCode 新建一个会话，内容进输入框。
- **App 已在前台**时分享：内容进**当前会话**输入框；若当前在设置页等无会话处，会新建会话并跳回聊天页。

## 常见问题

::: tip 内容太长怎么办
分享文本超过 2 万字符会自动截断前 2 万并提示。超长日志建议先存成文件再分享，或让 AI 在容器里直接读文件。
:::

::: warning 图片加载失败
若图片 URI 读取失败（如来源 App 撤销了权限），仅注入有效部分，并提示「部分图片加载失败」。文本不受影响。
:::

::: tip 没收到内容
若分享既无文本又无有效图片，AiCode 不创建会话、不弹窗，静默忽略。检查来源 App 是否实际选中了内容。
:::
